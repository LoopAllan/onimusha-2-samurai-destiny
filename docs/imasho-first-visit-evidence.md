# 今庄初訪・城鎮探索：來源稽核

查閱日期：2026-09-14。追蹤 [Issue #1](https://github.com/LoopAllan/onimusha-2-samurai-destiny/issues/1)，不是完整第一章驗收。

## 有限範圍

承接既有柳生之庄五節點，新增四節點：街口對話、酒館後院／二樓、市集／馬廄、鍛冶屋清路與升降台取弓。共九個可取得物與今庄地名，共十個新增實體。所有收集節點是建議，不宣稱必須依序觸發；順序採編輯閱讀路線，不是遊戲事件依賴圖。

終點是鍛冶屋取得弓，仍在城鎮。山道、通行證、礦山、同伴出場觸發、初次送禮限定回禮、羈絆數值、全商店購買及雞蛋變化留待後續，不以四張卡宣稱整次今庄初訪完成。既有白墨交換鏈是後續再訪，不是初訪前置。

官方 CAPCOM 版本介紹只支援版本定位，不能替這些城鎮拾取位置背書。繁中主名稱均為編輯暫譯；未取得繁中 UI 的名稱不因中文看似自然就標正式。Remaster 日文全部待核；PS2 地圖與弓的日文在此輪未建證，維持待核。

## 視覺證據與權利界線

九張 Remaster 取得畫面只作研究查閱，沒有加入網站、熱連結載入或重新散布；下列連結導向原發布者圖片。名稱來自畫面下緣的 `You obtained:` 文字，不是把 HTML alt／作者加上的註解當成遊戲 UI。鍛冶屋圖 036 左上角的操作提示是作者圖解，弓名稱則在下緣取得訊息直接可見；限時搭台路線另有兩版本各自正文支持。畫面沒有證明精確秒數，因此不寫秒數或永久漏拿。
